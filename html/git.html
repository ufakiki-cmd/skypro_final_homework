Git

    Базовые команды

  • git init (от initialize — инициализировать) — создаёт (инициализирует) новый пустой репозиторий Git в текущей папке.
  • git clone (от clone — клонировать, точная копия) — скачивает существующий удалённый репозиторий вместе со всей его историей.
  • git status (от status — состояние) — показывает текущее состояние рабочего каталога и индекса (какие файлы изменены, добавлены или удалены).
  • git add (от add — добавить) — добавляет изменения из рабочего файла в индекс (подготавливает к сохранению).
  • git commit (от commit — фиксировать, совершать) — сохраняет подготовленные в индексе изменения как новую точку (версию) в истории проекта.

    • Работа с ветками

  • git branch (от branch — ветка) — показывает список всех локальных веток или создаёт новую ветку.
  • git checkout / git switch (от checkout — проверить/переключиться, switch — переключить) — переключает вас на другую ветку или восстанавливает файлы.
  • git merge (от merge — слить, объединить) — соединяет изменения из другой ветки с вашей текущей веткой.

    • Синхронизация с удаленным сервером

  • git push (от push — толкнуть, нажать) — отправляет ваши локальные коммиты на удалённый сервер (например, GitHub).
  • git pull (от pull — тянуть) — скачивает изменения с удалённого сервера и сразу объединяет их с вашей текущей веткой.
  • git fetch (от fetch — принести, извлечь) — скачивает данные с удалённого сервера, но не объединяет их автоматически с вашим кодом, позволяя сначала посмотреть, что изменилось.
